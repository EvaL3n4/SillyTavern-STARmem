Mode chooses how memories reach the model. Automatic places them for you using the controls above. Macro exposes {{starmem-memories}} for you to drop into your preset wherever you want—placement controls do nothing in this mode. Off disables retrieval entirely.

Position: In-chat inserts the memory block among recent messages, Depth positions from the latest turn (0 = after the last message). In-prompt inserts before the chat history, near the system preamble—depth is ignored.

Role: most providers handle System well at any position. Some models (notably GLM) treat mid-conversation system messages inconsistently—switch to User or Assistant if memories seem to be ignored.
